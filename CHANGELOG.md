# Changelog

All notable changes to CryptoLife are documented here.

## [Unreleased]

### Added
- Agent guides: `claude.md`, `cursor.md`.
- CoinHub detail stats row: estimated mcap, 24h volume, and 1h change derived from live price history.
- Token dossier on investigate tokens (age, mcap, vol, rug risk, flags) — replaces non-functional investigate buttons.
- Trade modal slippage hint for thin-liquidity buys.
- Portfolio recent activity from `GAME.trades`.
- X Following tab filters feed to followed accounts.
- X cashtags link to CoinHub when `$SYMBOL` exists in `ASSETS`.
- X impersonator warning on tweet detail.
- Degen posts can reference live in-game symbols and prices.
- `ti-circle-check` icon for verified badges.

### Changed
- Version bump to v0.2.1 alpha.
- Home badges: only real X unread and CoinHub new-launch counts (preview apps no longer show fake badges).
- Fresh X posts (&lt;30 game min) get subtle highlight styling.
